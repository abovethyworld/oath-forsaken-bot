- **#rules** — Fully rewritten, 12 rules, onboarding steps, appeals process. Professional tone.
- **#clan-ranks** — 3 clean embeds, clickable roles, readable colors. Best-looking info channel.
- **#apply-here** — Welcome panel + streamlined application. Good first impression.

### Gaps & Ideas

#### Onboarding
1. **No #welcome channel** — New members land with no greeting. Bot idea #1 (welcome ping) needs a home. Suggest creating #welcome in General or Ranking/Info.
2. **No membership screening** — Discord's built-in rules screening (agree to rules before accessing server) isn't set up. This is standard for public servers.
3. **No server welcome screen** — Discord's welcome screen (describe your server + recommended channels) not configured.

#### Channels
4. **#suggestions** — Deferred earlier. Standard for community servers. Could use simple upvote/downvote reactions.
5. **#faq** — Common questions (how do ranks work? how do I link my RSN? what's FFA?) Currently scattered across #rules and #clan-ranks.
6. **#bot-commands is in Staff category** — Can regular members use bot commands? If yes, it should be visible to them. If no, fine as is.
7. **No #media/clips channel** — #event-photos covers events, but no general place for funny clips, screenshots, memes. #general absorbs this now.
8. **Voice channels** — Were set up earlier (War Camp, Chaos Altar, PVM 1/2, etc.) but not verified in this audit.

#### Visual / Branding
9. **Server icon** — Unknown if custom icon is set. Should be Zamorak-themed.
10. **Server banner** — Nitro-boosted servers get a banner. Worth checking.
11. **#roles has no banner** — #rules and #clan-ranks have banners. #roles doesn't. Inconsistent.
12. **#announcements has no banner** — Same as above.
13. **Invite splash** — Custom invite background for vanity URL (if they get one).

#### Roles
14. **No "New Member" role** — Currently new joins have no role until approved. A temporary "New" role could help staff identify pending applications.
15. **Event participant roles** — For bingos/comps, temporary roles could help organize (e.g., "Bingo Team 1").
16. **Donator/booster role** — If anyone boosts the server, no recognition role exists.

#### Bots & Automation
17. **Covered in BOT_IDEAS_BRAINSTORM.md** — Welcome ping, rank-up announcements, WOM auto-roles, ticket transcripts, multi-type tickets, etc.

#### Moderation
18. **No automod config reviewed** — Discord's built-in AutoMod (spam filter, blocked words) — is it on?
19. **No raid protection** — If the server goes public, consider verification level, anti-raid bot.
20. **Audit log** — Who can view it? Currently Warmonger+ per earlier setup.

#### Community
21. **No #introductions prompt** — #introduce-yourself exists but has no pinned template (name, RSN, goals, favorite boss, etc.)
22. **No regular events scheduled** — #event-calendar exists but is it populated? A weekly PvM night or skilling event would give people a reason to stick around.
23. **No clan goals** — A pinned "clan goals" (e.g., "10 members by X date", "first bingo on X") gives the early community something to rally around.

### Priority Suggestion (if opening doors soon)
1. Set up membership screening + welcome screen (30 min, big impact)
2. Create #welcome channel with bot greeting (ties into bot idea #1)
3. Add #suggestions channel (easy win)
4. Pin an intro template in #introduce-yourself
5. Check server icon/banner are set
6. Schedule the first event (even a casual one)

### Second Pass — Deeper Improvements

#### First 5 Minutes (New Member Experience)
23. **Invite link** — Do you have a custom/discord.gg vanity URL? `discord.gg/oathforsaken` is way more shareable than a random string.
24. **#rules is great, but it's long** — The TL;DR helps. Consider if the full 12 rules could be collapsible or if new members actually read them.
25. **Application wait time** — How long does approval take? If staff aren't online, new members sit in limbo seeing only 3 channels. An auto-acknowledgment ("we've got your application, hang tight") would help.

#### Engagement (What Keeps People Around)
26. **Are any WOM comps actually running?** — The system is set up beautifully, but an empty competition schedule looks dead. Even a small test comp would show life.
27. **#event-calendar is empty?** — If there are no events scheduled, the channel looks abandoned. One recurring weekly event (PvM night, skilling Sunday) would fix this.
28. **Conversation starters** — New servers die from silence. Ideas: weekly discussion question in #general, "drop of the week" thread, poll in #voting to get people clicking.
29. **#hall-of-chaos purpose** — Is this clear to new members? A pinned post explaining "post your biggest drops/achievements here" would help.

#### Content Channels
30. **#osrs-news source** — Is this manually updated or fed by a bot? If manual, it'll go stale. Consider a news bot or RSS feed.
31. **#sacrifices** — What's the purpose? If it's not obvious, new members won't use it.
32. **Channel topics** — Do all channels have descriptions? Hovering a channel should tell you what it's for. Quick audit worth doing.

#### Polish
33. **Pinned messages** — Key channels (#find-a-team, #goals-and-achievements, #introduce-yourself) should have pinned templates or guidelines.
34. **Custom emoji for polls** — #voting could use custom yes/no emojis instead of default reactions. Small touch, looks professional.
35. **Consistent naming** — Most channels are lowercase-hyphenated. Check for outliers.

#### Trust
36. **Staff list visibility** — Can members easily see who the staff are? #clan-ranks has Staff Roles, which is good. But is it obvious who to contact for what?
37. **Transparency** — Consider a #server-updates channel (public) for "we changed X" announcements. Builds trust.
